Get started by creating a new file or uploading an existing file. We recommend every repository include a README, LICENSE, and .gitignore.

……or create a new repository on the command line
echo "# Cpp" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/BestTry/Cpp.git
git push -u origin main


…or push an existing repository from the command line
git remote add origin https://github.com/BestTry/Cpp.git
git branch -M main
git push -u origin main

To delete a repository within GitHub (www.github.com)
Select the repository then go to "Settings" on the 
top menu bar then scroll down into the danger zone
and select the option to delete the repository
